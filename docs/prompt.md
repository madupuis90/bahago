This project is an old school web based tick based game. It has a medieval theme. The tick is every hour and we calculate resource increase or decrease, decrement army movement and army training timer, decrement technology or building construction timer. The rate at which you gather resource is based on the allocation of population into different tasks in percentage and your amount of population. 

Before implementation, I would like to understand how to structure my database tables. 


-----

I am building this tick based web game. Each player will be building a base on a 2d grid. They gather resource, build buildings and armies. They can fight eachother and team up. I have come up with 3 archetype: science, religion and magic.


Science:

- Industrial type
- Machines, defence towers, siege engines
- Better upgrades
- Better material/resource gathering
- High cost of wood/mineral
- Morality: progress, expansion, gain


Religion:

- Clergy type
- Devotion resource
- Worshipper stronger based on devotion
- Miracles/intervention (luck based?)
- Prayers for buffs
- Morality: Lawful, greater good, Order


Magic:

- Mystical type
- Mana resource
- Can cast spells through rituals (wards, curse)
- Can call creatures from another realm
- Morality: Laws of nature, equilibrium,elements
